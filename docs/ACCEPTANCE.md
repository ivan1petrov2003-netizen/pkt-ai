## Как проверить (одинаково для всех лаб)

1. Откройте файл в Packet Tracer (двойной клик).
2. Кликните на **PC** (любой) → вкладка **Desktop** → **Command Prompt**.
3. Наберите `ping <адрес>` из таблицы ниже и нажмите Enter.
4. **ВАЖНО: первый пинг почти всегда теряет 1–2 пакета** — это нормально
   (устройства знакомятся, ARP). Пустите пинг **второй раз** — должны быть
   `Reply from ...` без потерь. Если и второй раз `Request timed out` — вот тогда проблема,
   скажите мне название файла и что пинговали.
