## Порядок проверки (важно соблюдать по порядку!)

1. Откройте файл в Packet Tracer.
2. **Сначала ускорьте время**: в ПРАВОМ НИЖНЕМ углу окна есть кнопка **«>>» (Fast Forward Time)** —
   нажмите её 10–15 раз подряд. Это «проматывает» внутренние часы сети, чтобы свитчи и роутеры
   договорились между собой. Без этого первые 30–60 секунд пинги могут падать — это НЕ поломка.
3. Кликните на **PC** из таблицы → вкладка **Desktop** → **Command Prompt**.
4. `ping <адрес>` из таблицы.
5. Первый пинг может потерять 1–2 пакета (ARP) — **пустите его второй раз**.
   `Reply from ...` без потерь = успех.
